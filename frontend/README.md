# 📖 Sobre o Projeto

A **FittNutri** é uma plataforma digital desenvolvida para revolucionar a forma como nutricionistas e pacientes interagem.

Nossa missão é oferecer uma solução **completa, integrada e acessível**, unificando todas as ferramentas essenciais da prática clínica em um único ambiente.

Com a FittNutri, é possível:

- 📅 Gerenciar consultas  
- 📊 Acompanhar evolução de pacientes  
- 📄 Gerar relatórios visuais  
- 💬 Manter comunicação contínua  
- 📈 Visualizar métricas e progresso  

Tudo isso em um só lugar.

---

# 💡 Motivação

O mercado de saúde e bem-estar no Brasil está em plena expansão, porém muitos nutricionistas enfrentam dificuldades devido à fragmentação de ferramentas digitais.

Hoje, profissionais precisam lidar com múltiplos softwares pagos e desintegrados, impactando diretamente sua produtividade.

📊 Dados relevantes:

- 73,2% dos nutricionistas ganham entre 1 e 5 salários mínimos  
- Softwares profissionais podem custar em média R$ 800 por ano cada  

A **FittNutri** nasce para democratizar o acesso à tecnologia, permitindo que os profissionais foquem no que realmente importa:

❤️ Atendimento humanizado e eficiente.

# 🚀 Como Rodar o Projeto

## 📋 Pré-requisitos

- Node.js 18+
- npm 9+
- Git
- Banco de Dados (MySQL ou MongoDB)
- Java 17+ (caso utilize backend Java)

---

## 🔄 1. Clone o Repositório

```bash
git clone https://github.com/Grupo-6-ADS-B/Jane-Nutri.git
cd Jane-Nutri
```

---

## 📦 2. Instale as Dependências

### Frontend

```bash
cd frontend
npm install
```

### Backend (Java)

Abra o projeto backend (pasta `backend` ou `nutri`) no IntelliJ IDEA ou outro IDE Java.
O Maven irá baixar as dependências automaticamente.

---

## 🏁 3. Rode o Projeto

### Backend

Execute o projeto Java pelo IntelliJ IDEA (Spring Boot).

### Frontend

Abra um terminal na pasta `frontend` e execute:

```bash
npm run dev
```

---

## ⚡ Observações

- Configure o banco de dados (MySQL ou MongoDB) conforme necessário nos arquivos de configuração do backend.
- O frontend estará disponível em `http://localhost:5173` por padrão.
- O backend estará disponível em `http://localhost:8080` (Spring Boot).
