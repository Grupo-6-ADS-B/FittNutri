📄 Fluxo de Requisição HTTP

1
Usuário acessa https://www.fittnutri.site
2
Namecheap resolve CNAME → ALB DNS
3
ALB termina TLS (ACM) e encaminha para target group app :8080
4
Nginx (container) roteia: /api/ → backend, / → frontend
5
Backend consulta MySQL via JDBC (rede privada 10.0.x.x)
6
Resposta retorna pela mesma cadeia ao navegador

☁️ Fluxo Assíncrono — PDF para S3

1
Usuário solicita envio do PDF da dieta
2
POST /api/meals/patient/{id}/pdf/request
3
PdfProducerService publica mensagem em pdf.generation via AMQPS (NAT → CloudAMQP)
4
PdfConsumerService consome e gera PDF com OpenPDF
5
S3Service faz upload via DefaultCredentialsProvider (LabInstanceProfile → S3)
6
PDF salvo em pacientes/NOME/consultas/data-id.pdf

🔧 Fluxo de Deploy / Redeploy

1
Push para branch claude-test no GitHub
2
SSM SendCommand na EC2 App (sem SSH, sem bastion)
3
git pull + docker compose up --build backend
4
ALB health check detecta novo container saudável em ~30s

📈 Fluxo de Monitoramento

1
Prometheus scrape a cada 15s em App:8080/actuator/prometheus (rede privada)
2
Métricas: JVM, HTTP latency, DB connections, custom
3
Grafana consome Prometheus como datasource
4
Acesso via https://fittnutri.site/grafana/ → ALB → Monitoring EC2 :3000
